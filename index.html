NimbusBridge is built specifically for the Bluetooth SteelSeries Nimbus+ and the Mac App Store edition of Farming Simulator 25 (FS25). It maps physical controller input to a virtual gamepad with a dedicated FS25 profile.

Why NimbusBridge exists

A dedicated controller
profile for FS25.

FS25 uses device identities to select controller mappings. NimbusBridge exposes the Nimbus+ input through a virtual device with the identity and control layout targeted by the included FS25 profile.

FS25 setup

Connect, configure,
then launch FS25.

◉

Connect

Pair the SteelSeries Nimbus+ over Bluetooth and open NimbusBridge to view its input.

⌘

Configure

With FS25 closed, run FS25 Setup to install the device profile and add missing menu bindings. The app backs up changed game files.

↗

Start emulation

Start emulation, wait for the virtual controller, and then launch Farming Simulator 25.
